一、 数据与人工智能方向（支持金额不超过 30万元）
1. 面向大模型训练的合成数据训练前质量评估与校验方法研究
研究背景
当前大模型训练日益依赖合成数据（包括合成轨迹、合成指令、合成推理链等）作为高
质量数据供给的重要来源。然而，合成数据的质量评估面临一个根本性瓶颈：数据质量的验
证严重依赖下游反馈。现有流程为：合成数据生产 → 数据清洗/过滤 → 消融实验（训练
小模型验证）→ 评估模型效果 → 反推数据质量 → 迭代数据生产策略 → 再次合成 →
再次训练验证。该流程存在三个核心问题：
1) 反馈链路过长：从数据生产到获得质量结论需要经历完整的训练+评估循环，周期通常
以天甚至周为单位，严重影响数据迭代效率；
2) 资源消耗巨大：每次数据质量验证都需要消耗大量 GPU 算力进行训练。当前团队服务
于百灵、医疗大模型、金融大模型等多个模型方向，合成数据体量大，逐一训练验证的
算力成本不可持续；
3) 信号滞后且间接：训练后评估得到的是一个聚合的"模型效果"信号，无法精确定位到"
哪些数据好、哪些数据差、哪些数据有害"，只能给出整体数据的粗粒度判断；
团队希望突破这一瓶颈，建立训练前数据质量预测能力——在合成数据进入训练流程之
前，就能对其质量、有效性和潜在风险进行量化评估，从而大幅缩短数据迭代周期、降低算
力消耗、提升数据资产的投入产出比。

2. 面向企业的结构化数据基座模型关键技术研究
研究背景
用户增长、搜索推荐、广告营销、数字金融和风险控制等业务场景包含大量基于结构化
数据的分类、回归、排序、时间序列预测、聚类与异常检测任务。当前主要采用“一场景一
模型”的建设方式，每个新任务都需要重新进行数据处理、特征工程、模型选型、训练调参
和效果验证，研发周期长、人工成本高，并造成数据规律、特征能力和模型知识难以跨场景
复用。在冷启动、小样本、标签稀缺及业务快速变化的场景下，传统建模方式的局限更加明
显。
基础模型通过大规模预训练形成通用能力，并以少量样本或轻量化微调快速适配下游任
务，已推动自然语言和计算机视觉领域的技术范式变革。但结构化数据具有字段语义异构、
数据类型多样、表间关系复杂、数据分布差异大等特点，尚缺乏能够统一适配多种业务数据
与建模任务的通用基础模型。
本课题拟研究面向多场景、多任务的结构化数据基础模型，通过统一数据表示、跨数据
集预训练和高效任务适配，学习可迁移、可复用的结构化数据通用能力，支持分类、回归、
时序、聚类和异常检测等多类任务，为新业务场景快速构建高质量强基线。研究成果有望推
动结构化数据建模从“一场景一模型”向“一套预训练模型适配多类任务”转变，缩短模型研发
周期，降低建模成本，提升小样本和冷启动场景下的模型效果，为企业规模化、标准化和智
能化的数据建模提供技术基础。

3. 面向用户反馈闭环的大模型研发实验自动化与自迭代关键技术研究
研究背景
大模型进入真实业务后，用户纠错、重复提问、结果采纳、任务完成情况及专家复核意
见持续产生，但这些反馈往往稀疏、有噪声，且与模型版本、数据、提示词、检索结果和执
行轨迹分散存储。研发团队难以判断问题的真实原因，也难以将典型失败转化为可复现的评
测样本和可验证的改进实验。离线评测结果与用户实际体验可能不一致，而完整训练实验成
本高、周期长，进一步制约了迭代效率。
本课题拟研究以真实用户反馈为起点的大模型研发实验自动化方法，构建“反馈采集与
校准—失败诊断—实验假设生成—成本感知的分级验证—线上效果检验—经验沉淀”的闭环。
由人设定业务目标、实验预算与上线约束，智能体辅助完成问题发现、实验设计与执行、结
果分析和下一轮建议，使用户反馈持续转化为可验证的研发决策。
预计产出
1) 报告：提交结项验收表，提交结项验收报告
2) 论文：投稿 CCF-A 类及蚂蚁认可的期刊/会议论文 1-2 篇并最终收录，提供论文底稿及
收录邮件
3) 专利：乙方协助蚂蚁和/或其关联公司提交国内、国际专利 1 项，交付符合本项目创新
点的专利申请号和专利申请相关材料
4) 算法原型：
a. 形成一套用户反馈与研发轨迹关联机制。 建立反馈、会话/任务、模型与配置版本、检
索和工具调用轨迹、评测结果的统一表示；对反馈进行去噪、分层抽样和专家校准，形
成可追溯的问题样本池；

取从周级缩短到天级；在相同实验预算和预先定义的有效性门槛下，使无效实验占比相
对下降 20%—30%；
b. 由研发专家独立复核自动分析报告与下一轮建议，目标是建议采纳率达到 30% 以上；
同时以预先指定的线上用户指标和时延、成本约束验证实际收益，避免仅凭离线评分宣

4. 面向可信医疗知识服务的医疗概念体系与关键技术研究
研究背景
可信医疗知识服务正从通用问答走向“依据充分、结论可解释、过程可追溯”的新阶段，
其基础在于统一、可扩展的医疗概念体系。当前医疗知识分散于标准术语体系、临床指南、
药品说明书、医学文献、临床试验及业务数据中，存在概念标准不统一、别名缩写复杂、跨
源映射困难、证据粒度不一致等问题，导致疾病、药品、检查、治疗、证据等核心对象难以
一致表达与稳定复用。现有 RAG 方法主要基于文本切片与语义召回，面对复杂医疗问题时
易出现实体混淆、证据覆盖不足、多跳推理能力弱和来源冲突不可控等问题，难以支撑高可
信医疗知识服务。本课题围绕“医疗概念体系”这一核心底座，研究实体标化与链指、知识
增强检索、复杂问题自动研究、冲突检测与解决等关键技术，形成支撑可信医疗知识服务的
一体化方法体系。
本课题围绕可信医疗知识服务需求，重点开展四方面研究：
（1）医疗概念体系构建：基于 OMOP 等标准，构建覆盖疾病、药品、检查、治疗、指
南、文献和证据对象的统一概念体系与语义框架；
（2）实体标化与跨源链指：研究面向中文医疗场景的实体识别、标准化、消歧和多源
对齐技术，提升知识统一表达能力；
（3）知识增强检索与复杂问题自动研究：研究面向复杂医疗问题的概念扩展、混合召
回、领域 reranker、多跳检索与自动研究机制，提升复杂问题求解能力；
（4）冲突检测与解决：构建证据组织与冲突裁决方法，提升结论可信性与可解释性。
实施上采用“概念体系建设—核心算法研发—原型系统集成—场景评测验证”的技术路
线，形成可落地的关键技术方案与原型系统。

6. 面向大模型基础设施的递归自优化与缺陷自修复技术研究
研究背景
随着大模型架构、训练规模及推理系统复杂度持续增长，大模型基础设施的性能优化、
正确性保障与故障治理面临日益复杂的系统性挑战。模型、训练框架、编译器、运行时、通
信网络及硬件之间高度耦合，问题定位与优化往往需要跨越多个技术层次，依赖少数领域专
家的知识与经验。当前，从系统观测、问题诊断、优化方案生成，到代码修改、实验验证和
生产发布，仍存在链路长、人工介入多、试错成本高、历史经验难以复用等问题。传统依赖
人工分析、固定规则和静态自动化脚本的工程方式，难以适应模型架构与基础设施的快速演
进，逐渐成为制约模型迭代效率和基础设施规模化发展的关键瓶颈。近年来，大模型在代码
理解、复杂推理、工具调用和长链路任务执行方面的能力不断提升，为 AI 深度参与基础设
施研发与运维提供了新的技术可能。然而，现有 Agent 技术仍主要聚焦单次任务执行，缺
乏对复杂系统的深度理解、可靠的实验验证机制，以及跨任务积累和复用工程经验的能力，
尚难形成持续自我改进的工程闭环。
本课题拟研究面向大模型基础设施的 RSI（Recursive Self-Improvement）关键技术，构
建“系统观测—问题诊断—方案生成—自动实验—效果验证—安全执行—经验学习”的自主
优化闭环，使 AI 能够深入模型训练与推理系统，持续提升基础设施的性能、正确性与稳定
性。课题重点探索性能自优化、精度自对齐、缺陷自修复三类核心能力，并研究支持跨任务
经验积累、自适应策略优化和持续能力演进的 Self-Evolving Agent Harness，形成可验证、
可复用、可持续改进的智能工程技术体系。

研究背景

正成为提升智能体能力的重要技术路径。与传统基于静态数据的模型训练不同，Agentic RL
需要模型与环境持续交互，通过执行任务、观察状态变化和获取反馈实现策略优化。因此，
高质量、可规模化的交互环境正成为制约智能体训练效率与能力提升的关键基础设施。真实
业务环境广泛涉及网页、应用、API、代码仓库、操作系统以及复杂的用户与系统状态。直
接使用真实环境进行训练，面临环境构建成本高、并发能力受限、状态难以复现、外部依赖
不稳定以及数据安全风险等挑战，难以支撑大规模强化学习和持续模型迭代。现有环境构建
方式主要依赖人工开发、规则模拟或预先录制的交互轨迹，在环境保真度、任务多样性、状
态覆盖率和自动化生成能力方面仍存在明显不足。尤其是如何保持虚拟环境与真实环境的行
为一致性，如何生成具有有效学习价值的任务，以及如何验证虚拟环境训练效果能够迁移至
真实环境，仍是需要重点突破的研究问题。
本课题拟研究从真实环境到可执行虚拟环境的自动化转换技术，将真实系统的界面、接
口、状态、行为约束及任务流程抽象为可复现、可控制、可验证的环境模型；进一步研究环
境规模化生成、并行执行、任务难度自适应演化及环境生命周期管理，形成从真实环境采集、
虚拟环境构建到训练反馈驱动环境演化的完整技术体系。

9. 图像与视频 Token 化智能编码技术研究（备注：本课题支持金额不超过 50
万元）
研究背景
随着移动互联网普及，全球视觉数据量激增，视频流量占比超 80%。然而，传统编码
标准（如 H.266/VVC）依赖手工模块且以像素失真为优化目标，在极低码率下易产生块效
应，且缺乏语义建模，难以直接服务于分类、生成等下游智能任务。在大模型时代，视觉压
缩亟需同时满足极高压缩率、丰富语义保留及面向智能任务的直接可用性三重需求。
在此背景下，"Token 化”成为连接压缩与理解的关键范式，推动编码从“面向人眼”
向“面向智能”演进。当前研究呈现三大趋势：一是利用一维 Latent Token 捕获全局语义，
实现重建与生成的统一；二是突破传统运动补偿，通过时空掩码与记忆机制实现视频高效压
缩；三是构建统一离散 Token 空间，使云端大模型无需像素重建即可直接消费压缩数据，
催生“压缩 - 理解 - 生成”一体化新范式。
尽管进展显著，现有研究仍面临三大瓶颈：首先，图像与视频 Token 化缺乏统一框架，
模态间难以共享表示空间；其次，Token 语义丰富度与压缩效率的权衡尚未系统探索，极低
码率下语义保持能力不稳定；最后，面向大模型的自适应编码策略不成熟，无法根据任务动
态筛选关键 Token 子集。
针对上述问题，本项目旨在构建统一的图像与视频 Token 化智能编码框架。核心目标
包括：第一，设计基于一维隐 Token 的紧凑表示与率 - 失真 - 语义联合优化机制，在极
低码率（视频<0.02bpp，图像<0.05bpp）下实现从“像素保真”到“语义保真”的转变；第
二，打破“压缩 - 重建 - 处理”级联模式，构建跨模态统一 Token 空间与任务自适应传
输策略，实现“压缩即服务”。项目将通过双流 Token 化架构解决时空冗余，并支持云端
大模型直接消费压缩 Token 用于视觉问答、文生图等任务，在大幅降低带宽与计算开销的
同时，确保下游任务性能不低于基线方法的 95%，推动智能编码与视觉理解的深度融合。

1) 报告：提交结项验收表，提交结项验收报告
2) 论文：投稿 CCF-A 类及蚂蚁认可的期刊/会议论文 2 篇并最终收录，提供论文底稿及收

4) 标准提案：至少提交 2 项国际或国家标准提案，并被标准录用
5) 算法原型：研究图像与视频 Token 化智能编码算法，提升编码效率，同时保障语义保真
度和下游任务准确度。在低于 0.02bpp的码率下，LPIPS 指标优于 VTM-17.0 和 DCVC
系列方法。在低于 0.05bpp 的传输码率下，下游任务性能不低于基线方法（基于原始像

6) 技术指标：完成图像与视频 Token 化智能编码算法的设计，交付一套智能图像与视频

10. 三维媒体感知与交互技术研究（备注：本课题支持金额不超过 50万元）
研究背景
生成式人工智能正从“感知智能”迈向“空间智能”与“具身智能”，要求 AI 具备三
维理解、物理推理和现实交互能力。在此趋势下，三维高斯泼溅（3DGS）技术凭借其在渲
染速度、细节表达和训练效率上的显著优势，成为真实世界数字表示的主流手段，广泛应用
于数字孪生、自动驾驶、机器人等领域。
然而，空间智能要求系统不仅“看见”，更要理解空间结构、物体关系和物理约束。当
前 3DGS 在语义标注、动态建模和空间推理等方面仍有不足。为此，本项目旨在探索 3DGS
与多模态大模型、语义理解及物理约束的融合路径，推动三维世界从“可视化重建”向“可
理解、可编辑、可交互、可行动”的智能空间表达演进。
研究目标是实现面向三维场景的可泛化、在线分割跟踪与编辑交互框架，使单目标分割
小于 1秒，且分割指标超越现有离线方案 SAGA。针对当前逐场景训练的离线方案缺乏实用
性的问题，研究提出四步思路：
第一，解耦三维重建与分割。现有方法将重建与分割过程耦合，或需额外蒸馏时间，限
制了动态与在线应用。本研究直接以已建好的 3DGS场景为输入，实现在线三维高斯分割。
第二，实现亚秒级可泛化三维分割。为满足低延时和跨场景泛化需求，研究创新性地引
入“虚拟无人机”（v-drone）机制，将三维分割任务转化为虚拟无人机的飞行规划及其视
角下的二维跟踪任务，从而避免耗时的蒸馏学习，实现亚秒级可泛化目标分割。
第三，实现动态场景下的跟踪与分割。通过将 v-drone 扩展为“时空虚拟无人机”，使
用时序无人机在时域跟踪，空间无人机逐帧分割，并结合卡尔曼滤波进行运动建模以提升稳
定性。该框架为每个虚拟无人机配备二维基础模型并共享全局记忆力库，可统一处理动静态
场景。
第四，基于分割与跟踪实现场景编辑与交互。可对动静态场景进行物体级在线编辑操作，
如移除、复制、缩放等。通过进一步对齐世界坐标系、完善几何表示并添加物理属性，可支
持虚拟现实交互、三维场景理解及为具身智能提供“仿真到现实”的训练框架。

11. 面向研发风险前置防控的代码图谱增强技术与自进化多智能体框架技术研
究-子课题一（基于代码仓库精准分析技术的变更风险左移系统研发与应用）
研究背景
AI Coding 与智能体辅助研发正在加快代码生成和变更速度，研发阶段的风险防控既需
要判断代码及其变更是否存在缺陷，也需要识别这些缺陷可能影响的接口、消息、配置和业
务链路。传统人工评审难以持续覆盖大规模变更，静态规则扫描对复杂业务语义和隐式依赖
的识别有限，单一大模型分析则容易受到仓库上下文不完整、推理缺少证据和误报较多等问
题制约，导致风险难以在代码提交、评审及发布准入前得到充分识别和有效阻断。本课题围
绕“研发阶段代码异常提前识别与风险阻断”，研究代码图谱增强分析与自进化多智能体协
同审计方法。以代码、配置、框架语义、历史变更和运行观测等多源证据为基础，贯通仓库
上下文理解、变更影响分析、代码风险审计与反馈校正，形成能够说明风险位置、影响范围
和判断依据的分析能力，为研发人员修复缺陷、补充验证以及执行风险拦截提供依据。
该研究主要支撑以下关键业务方向：
支撑“变更风险拦截和定位”。将代码缺陷识别和影响范围研判前置到研发流程，为代
码评审、测试验证和发布准入提供风险及证据；同时依据影响范围支持精准监控配置和告警
关联，并将历史告警、故障处置和专家确认结果用于改进研发阶段的风险判断。
支撑智能代码评审与研发质量左移相关目标。依托 AntCR 场景验证多角色协同、自进
化和跨语言复用能力，减少无效风险提示与重复人工评审，提高研发阶段的风险发现效率，
为 AI 生成代码和人工编写代码提供一致、可追溯的质量检查。
